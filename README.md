# 🦷 DentWise

DentWise is a modern dental appointment booking and clinic management platform built with **Next.js**. It helps patients easily book appointments while giving clinics a smooth dashboard to manage schedules, consultations, and communications.

---

## ✨ Features

- 📅 Easy online appointment booking  
- 👨‍⚕️ Doctor & admin dashboard  
- 📧 Automated email confirmations  
- 🎙️ Voice assistant support  
- 🔐 Secure authentication system  
- ⚡ Fast, responsive UI  
- ☁️ Deployed on Vercel  

---

## 🚀 Live Demo

## 🛠️ Tech Stack

- Next.js

- TypeScript

- Tailwind CSS
